## TL;DR

스택은 "접시 쌓기"(마지막에 올린 걸 먼저 뺌, LIFO), 큐는 "편의점 줄서기"(먼저 온 사람이
먼저 나감, FIFO), 힙은 "병원 응급실 대기열"(온 순서가 아니라 가장 급한 사람이 먼저 나감,
우선순위 기반)이다. 셋 다 "데이터를 넣고 뺀다"는 점은 같지만, 어떤 걸 먼저 꺼낼지 규칙이
완전히 다르다.

## 비유 한 줄

스택 = 접시 쌓기(Last In, First Out) · 큐 = 줄서기(First In, First Out) · 힙 = 응급실
우선순위 대기열(값의 순서, 들어온 순서 무관).

## 개념 표

| 자료구조 | 비유 | 한줄 설명 |
|---|---|---|
| 스택(Stack) | 접시 쌓기 | LIFO, 한쪽 끝(top)에서만 push/pop, 함수 호출 스택·undo 기능에 사용 |
| 큐(Queue) | 편의점 줄서기 | FIFO, 한쪽(rear)에서 넣고 반대쪽(front)에서 뺌, 작업 대기열·BFS에 사용 |
| 힙(Heap) | 응급실 우선순위 대기 | 완전이진트리 기반, 부모-자식 간 크기 관계(최소/최대 힙)를 유지, 우선순위 큐 구현에 사용 |
| 최소 힙 / 최대 힙 | 제일 급한 환자가 맨 앞 / 제일 심각한 환자가 맨 앞 | 최소 힙=루트가 항상 가장 작은 값, 최대 힙=루트가 항상 가장 큰 값 |

## 구조 다이어그램

```
[스택]                    [큐]                       [최소 힙(완전이진트리)]
  push ↓   ↑ pop            enqueue →   → dequeue           1
     [30]                  [A][B][C][D]                    /  \
     [20]                   ↑front  ↑rear                 3    5
     [10]                                                 / \  /
  (맨 위만 접근)        (앞에서 빼고 뒤로 넣음)            4  8 7
                                                    (부모 ≤ 자식, 루트가 항상 최소)
```

## 동작 원리 (왜?)

| 질문 | 답 |
|---|---|
| 왜 함수 호출은 스택으로 관리하나? | 가장 최근에 호출된 함수가 가장 먼저 끝나고 돌아가야(LIFO) 호출 순서가 꼬이지 않기 때문 — 재귀호출 깊이가 너무 깊으면 "Stack Overflow"가 나는 이유도 이 호출 스택이 꽉 차서임 |
| 왜 BFS(너비 우선 탐색)는 큐를 쓰나? | 가까운 노드부터 순서대로(먼저 발견한 순서대로) 방문해야 "레벨별 탐색"이 되는데, 이게 FIFO 구조와 정확히 일치하기 때문 |
| 왜 힙은 배열로 구현하는데 "트리"라고 부르나? | 완전이진트리라서 부모-자식 관계를 인덱스 계산(`부모=i/2`, `왼쪽자식=2i`, `오른쪽자식=2i+1`)만으로 표현 가능 — 포인터 없이 배열만으로 트리 구조를 흉내낼 수 있음 |
| 왜 힙의 삽입/삭제는 O(log N)인가? | 삽입 시 맨 끝에 넣고 부모와 비교하며 위로 올라가고(heapify-up), 삭제 시 루트를 빼고 맨 끝 요소를 루트로 옮긴 뒤 자식과 비교하며 내려감(heapify-down) — 둘 다 트리 높이(log N)만큼만 비교하면 됨 |
| 힙은 왜 "정렬된 상태"가 아닌가? | 힙은 부모-자식 간 대소관계만 보장할 뿐, 형제 노드끼리는 순서가 없음 — "완전 정렬"보다 "최소/최대값을 빠르게 꺼내는 것"에 특화된 구조이기 때문 |

## 예시

```python
# 스택 (파이썬 list로 흉내)
stack = []
stack.append(10); stack.append(20)
stack.pop()        # 20 — 마지막에 넣은 것부터

# 큐
from collections import deque
queue = deque()
queue.append(10); queue.append(20)
queue.popleft()    # 10 — 먼저 넣은 것부터

# 힙 (파이썬 heapq는 최소 힙)
import heapq
heap = []
heapq.heappush(heap, 5)
heapq.heappush(heap, 1)
heapq.heappush(heap, 3)
heapq.heappop(heap)  # 1 — 항상 가장 작은 값부터
```

## 요약 표

| 구분 | 스택 | 큐 | 힙 |
|---|---|---|---|
| 순서 규칙 | LIFO (마지막 ↔ 처음) | FIFO (먼저 ↔ 먼저) | 우선순위 (값 기준) |
| 대표 용도 | 함수 호출, 괄호 검사, undo | 작업 대기열, BFS, 캐시 FIFO | 우선순위 큐, 다익스트라, 힙 정렬 |
| 삽입/삭제 복잡도 | O(1) | O(1) | O(log N) |
| 내부 구현 | 배열/연결리스트 | 배열/연결리스트 | 배열 기반 완전이진트리 |
