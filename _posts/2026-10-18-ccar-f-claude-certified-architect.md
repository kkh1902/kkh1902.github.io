## 한 줄

**CCAR-F(Claude Certified Architect – Foundations)**는 Anthropic이 만든 "Claude로
프로덕션 에이전트 시스템을 설계할 줄 아는가"를 평가하는 기술 자격증이다. 지난 1년 가까이
멀티에이전트 자동화 사무실(Agentic_office)을 직접 설계·운영해온 경험이 시험 범위 5개
도메인과 거의 그대로 겹친다 — 이 글은 그 겹치는 지점을 정리하고, 안 겹치는 부분만
공식 학습 과정(Anthropic Academy)으로 보강하는 계획을 세운 기록이다.

## 비유 한 줄

일반 자격증은 "책으로 배운 걸 시험 보는" 과정이지만, CCAR-F는 "이미 현장에서 하던 일에
이름표를 붙이는" 과정에 더 가깝다 — 운전을 1년 한 사람이 운전면허 이론 시험을 준비하는
느낌이다.

## 개념 표

| 용어 | 비유 | 한줄 설명 |
|---|---|---|
| CCAR-F | 면허 이론 시험 | Anthropic의 입문급 아키텍처 자격증 |
| Claude Partner Network | 면허 발급 기관 가입 | 응시 자격과 연결된 조직/계정 체계 |
| Anthropic Academy | 무료 운전 교습 영상 | 가입·구독 없이 누구나 듣는 무료 코스 |
| 시나리오 기반 문제 | 실기 시험 | 암기가 아니라 "이 상황에서 어떤 설계가 맞나" |
| CCAO-F / CCAR-P / CCDV-F | 2종/1종/화물면허 | 같은 자격증군의 다른 레벨·트랙 |

## 구조 다이어그램

```
[CCAR-F 시험] 60문항 · 120분 · 시나리오 기반 · 통과 기준 720/1000(비공식)
   │
   ├─ 27% 에이전트 아키텍처·오케스트레이션   ★★★ (Agentic_office로 이미 실무)
   ├─ 20% Claude Code 설정·워크플로우         ★★★ (CLAUDE.md 기반 운영 그 자체)
   ├─ 20% 프롬프트 엔지니어링·구조화 출력      ★★  (지시서 작성 경험, 이론 정리 필요)
   ├─ 18% 도구 설계·MCP 통합                  ★★  (MCP 다수 연결 운영, 설계 이론 보강)
   └─ 15% 컨텍스트 관리·신뢰성                ★★  (운영 경험 있으나 "이론 용어" 미정리)

   → 부족한 3개 도메인만 Anthropic Academy로 보강
     Claude 101 → Claude Code 101/in Action → Building with Claude API → MCP Series
```

## 동작 원리(왜 이 자격증을 지금 준비하나?)

| 질문 | 답 |
|---|---|
| 왜 "정파"(공채/코테) 대신 이 트랙인가 | 해커톤·강사 이력처럼 "성과로 보여주는" 전략과 같은 맥락 — 실무 경험을 공식 용어로 환산하는 작업에 가깝다 |
| 왜 공부량이 적게 든다고 보나 | 5개 도메인 중 비중 47%(아키텍처+Claude Code 설정)는 이미 Agentic_office 운영으로 충분, 나머지 53%도 절반은 겹친다 |
| 왜 전부 믿지 않고 "불확실"로 남기나 | 응시료·응시 자격·사전요건이 전부 3rd-party 출처 간 서로 충돌 — Anthropic 공식 페이지를 직접 열어 확인하지 못했다 |

## 확인 안 된 것 — 지어내지 않고 그대로 남긴다

여러 3rd-party 가이드를 비교했는데, Anthropic 공식 문서는 검색 결과로 뜨지 않아 직접
대조하지 못했다. 그래서 출처 간 충돌이 있는 부분은 아래처럼 "확정값" 대신 "출처별 차이"로
남긴다.

| 항목 | 출처 A | 출처 B |
|---|---|---|
| 응시료 | $125 | $99 |
| 응시 자격 | Anthropic 파트너사 직원 한정 + 사전 과정 4개 필수 | Claude Partner Network 멤버(무료 가입)면 가능, 하드 사전요건 없음 |
| 한국 응시 가능 여부·방식 | 미확인 | 미확인 |
| 삼성 등 채용/강사 포지션에서의 실제 인정 여부 | 미확인 | 미확인 |

확실한 것만 추리면: **60문항·120분·시나리오 기반, 통과 기준은 1000점 스케일 중 720점(비공식),
2026년 7월부터 버전 1.0 적용**이라는 점은 복수 출처가 일치한다. 그 외는 응시 전에 Anthropic
공식 페이지로 재확인이 필요하다 — 나는 현재 Claude Partner Network 가입을 신청한 상태이고,
"응시 자격이 안 나와도 공부 차원에서 학습은 계속한다"는 입장으로 진행 중이다.

## 예시 — 도메인별 내 경험 매칭

실제로 Agentic_office에서 해본 것들을 시험 도메인 용어로 바로 옮겨보면 이렇다.

```text
도메인: 에이전트 아키텍처·오케스트레이션 (27%)
  시험 용어          →  내가 실제로 한 일
  orchestrator-worker  카드뉴스팀 planner→writer→designer→reviewer→publisher
                        5단계 파이프라인(발행 권한을 제작 단계에 안 몰아줌)
  프롬프트 라우팅       콘텐츠 키워드로 schedule-secretary vs email-manager 분기
  병렬화/순차화 판단    Remotion 렌더는 메모리 제약으로 "순차 실행"으로 명시 제한

도메인: 도구 설계·MCP 통합 (18%)
  시험 용어          →  내가 실제로 한 일
  모호한 상황 대비     Aside 읽기 전용 원칙 + 승인 대기 시 타임아웃 처리
  MCP로 외부 연동      Supabase/Slack/workspace-mcp 등 다수 연결, 최소 스코프 원칙
```

빈약한 부분(이론 용어로 정리 안 해본 것)은 "컨텍스트 관리·신뢰성" 도메인의 에스컬레이션
로직·에러 처리 패턴 명칭들이다 — 운영 중 "타임아웃나면 @@ASK@@로 멈춘다"처럼 실제로는
하고 있지만, 그걸 시험이 쓰는 정식 용어(예: escalation path, graceful degradation)로
연결하는 작업이 남아있다.

## 요약 표

| 도메인 | 비중 | 준비 전략 |
|---|---|---|
| 에이전트 아키텍처·오케스트레이션 | 27% | 추가 학습 불필요, 용어만 정리 |
| Claude Code 설정·워크플로우 | 20% | 추가 학습 불필요, 용어만 정리 |
| 프롬프트 엔지니어링·구조화 출력 | 20% | Academy "Building with Claude API"로 보강 |
| 도구 설계·MCP 통합 | 18% | Academy "MCP Series"로 설계 이론 보강 |
| 컨텍스트 관리·신뢰성 | 15% | Academy 코스 + 에스컬레이션/에러 처리 용어 정리 |

응시 자격·비용은 아직 출처가 엇갈려 확정하지 못했고, Claude Partner Network 가입 결과를
보고 다음 단계(실제 응시 신청)를 결정할 계획이다.
