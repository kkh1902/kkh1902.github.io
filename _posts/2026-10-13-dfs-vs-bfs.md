## TL;DR

DFS(깊이 우선)는 "미로에서 한 길을 끝까지 가보는 것", BFS(너비 우선)는 "같은 층부터
한 바퀴 다 돌아보는 것"이다. **최단 거리가 필요하면 무조건 BFS**, 모든 경로를
탐색하거나 메모리를 아껴야 하면 DFS를 쓴다.

## 비유 한 줄

DFS = 갈림길마다 왼쪽 길로 막다른 곳까지 가보고, 안 되면 되돌아와 다음 길을 시도.
BFS = 출발점에서 한 걸음씩 갈 수 있는 모든 곳을 동시에 넓혀가며 탐색(물결이 퍼지듯).

## 개념 표

| 용어 | 비유 | 한줄 설명 |
|---|---|---|
| DFS(Depth-First Search) | 한 길을 끝까지 파고들기 | 스택(재귀) 기반, 한 방향으로 갈 수 있는 데까지 간 뒤 백트래킹 |
| BFS(Breadth-First Search) | 동심원처럼 퍼져나가기 | 큐(Queue) 기반, 현재 노드에서 1칸 거리부터 차례로 방문 |
| visited 배열 | 이미 가본 곳 표시 | 같은 노드를 중복 방문해 무한루프에 빠지지 않게 막음 |
| 백트래킹 | 막다른 길에서 되돌아가기 | DFS가 더 갈 곳이 없을 때 이전 분기점으로 복귀 |

## 구조 다이어그램

```
그래프:        1
              / \
             2   3
            / \   \
           4   5   6

[DFS 방문 순서] 1 → 2 → 4 → 5 → 3 → 6  (한쪽 가지를 끝까지 내려간 뒤 옆으로)
[BFS 방문 순서] 1 → 2 → 3 → 4 → 5 → 6  (가까운 거리(레벨) 순서대로)

DFS 자료구조: 스택/재귀 (후입선출)   BFS 자료구조: 큐 (선입선출)
```

## 동작 원리(왜?)

| 질문 | 답 |
|---|---|
| 왜 BFS가 최단 거리를 보장하나? | 레벨(거리) 순서대로 방문하기 때문에, 처음 도착하는 순간이 곧 최단 경로다 — DFS는 먼 길을 먼저 탐험할 수도 있어서 보장 안 됨 |
| 왜 DFS는 재귀로 자연스럽게 구현되나? | 재귀 호출 스택 자체가 "지금까지 온 경로"를 저장하는 구조라 명시적 스택 없이도 깊이 우선 탐색이 됨. 단 그래프가 매우 깊으면 스택 오버플로 위험 |
| 메모리는 어느 쪽이 더 적게 쓰나? | DFS는 현재 경로 깊이만큼만 기억하면 되지만(O(깊이)), BFS는 같은 레벨의 모든 노드를 큐에 쌓아야 해서 그래프가 넓을수록 메모리를 더 씀 |
| 실무/코테에서 구분 기준은? | "최단 경로/최소 횟수"가 키워드면 BFS(미로 최단거리, 단어 변환 최소 횟수). "모든 경우의 수/조합"이 키워드면 DFS(백트래킹, 순열·조합, 연결 요소 찾기) |

## 예시

```python
from collections import deque

graph = {1: [2, 3], 2: [1, 4, 5], 3: [1, 6], 4: [2], 5: [2], 6: [3]}

def dfs(start):
    visited, stack, order = set(), [start], []
    while stack:
        node = stack.pop()
        if node not in visited:
            visited.add(node)
            order.append(node)
            stack.extend(reversed(graph[node]))
    return order

def bfs(start):
    visited, queue, order = {start}, deque([start]), []
    while queue:
        node = queue.popleft()
        order.append(node)
        for nxt in graph[node]:
            if nxt not in visited:
                visited.add(nxt)
                queue.append(nxt)
    return order

print(dfs(1))  # [1, 2, 4, 5, 3, 6]
print(bfs(1))  # [1, 2, 3, 4, 5, 6]
```

## 요약 표

| 상황 | 선택 | 이유 |
|---|---|---|
| 최단 경로/최소 이동 횟수 | BFS | 레벨 순서 탐색이라 처음 도달이 곧 최단 |
| 모든 경로/조합을 다 봐야 함 | DFS | 백트래킹으로 모든 분기를 체계적으로 탐색 |
| 그래프가 매우 넓고 얕음 | DFS | BFS는 큐에 노드가 폭발적으로 쌓여 메모리 부담 |
| 그래프가 매우 깊음 | BFS | DFS는 재귀 깊이 한계/스택 오버플로 위험 |
